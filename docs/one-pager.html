LegalOPC· 一页纸介绍 基于发布会演讲稿 v2.0

LLM 拆了法律交付的现金门槛；一个法律人 + AI，以 OPC（一人公司）形态，就是一个完整、能自负盈亏的交付单元——向所有法律人敞开的新组织形态与一门新职业。

一句话定位

LegalOPC 中文称「法律超级个体」（法务一人公司）——不是一个产品，也不是某家公司，而是一种新组织形态、一门新职业。 它让每个法律人都能以 OPC 一人公司 / 合规咨询公司形态，在 AI 加持下独立交付企业法务与合规服务（合同 / 劳动 / 数据合规 / 广告法）为核心画布；人担责、AI 为外延，订阅 / 月费即可自我造血，股权仅作极罕见的可选对齐红利。
边界：不限律师或法务出身，定位在交付域而非入场身份；律师轨可涉诉讼代理（须律所执业证通道），不碰刑辩、不以律师名义出意见书。

为什么是现在

真实需求：数千万中小企业的持续合规

  • 合同、用工、数据、广告——高频合规刚需，单件出问题就伤筋动骨
  • 请不起、也找不到合适的律师；要的是持续性法务，不是单点救火
  • 前序法律科技（LegalZoom、ALSP 等）与早期行业探索，只改变了渠道、或做了替代性服务供应商（ALSP）——没有真正改变法律工作的生产力。它们撞到的也只是需求的一角：海量创业公司的股权期权焦虑、每天新生的企业（如调研显示 91% 早期法律问题集中于股权期权、日均 1.66 万新企）——冰山一角，非总需求证明

LLM 是真正的变量

  • 2022 ChatGPT 发布：判断力第一次可被结构化编码、规模化部署
  • 标准层边际成本被压到近乎为零：白皮书原话「过去一份交付需团队，今天一个受训练的人 + AI 就是完整交付单元」
  • 一个法律人，能服务过去十倍的公司——当年压不下来的单位成本，现在能压下来

对照：前序法律科技改的是「渠道与供给形态」（ALSP、自助表单），LegalOPC 借 LLM 改的是「生产力本身」——生产层成本趋近于零、单位经济首次压得下来。这是同一头大象，两种打法。

LLM 冲击：法律工作三层拆解

生产层
合同起草 / 法律检索 / 文书处理 → AI 把成本压到趋近于零
策略：AI 自动覆盖，低价/免费订阅做入口
控制层
风险判断 / 审批 / 质量把关 → AI 做大部分、但不能最终裁决
策略：人带着 AI 下场，订阅 + 项目制现金
责任层
签字 / 执业背书 / 合法性来源 → 不可自动化、不可外包、不可压缩
策略：人被收缩到这一唯一不可替代的节点——人担责，AI 为外延

AI 吞掉生产层、放大控制层、唯独啃不动责任层——这正是 LegalOPC 的立脚点。

北京智能体新政明确支持「以 OPC（一人公司）为代表的创新创业新模式」——LegalOPC 正好踩在同构点上，每个法律人自己就是一家法务机构，没有母公司、没有上级。

入场两轨：谁能成为 LegalOPC 按业务边界设门槛

受雇轨（主体市场）

  • 入场门槛：法律学位 或 法律行业 N 年经验
  • 以机构雇员身份执业，责任由雇佣机构兜底
  • 供给侧主流、最稳，对应最大市场

自雇轨（先锋市场）

  • 入场门槛 按业务边界设：非诉服务（合同 / 劳动 / 数据合规 / 广告法）可由工商登记的法律服务·合规咨询公司交付，不强制法考
  • 律师专属的民事诉讼代理须以律所执业证通道承接、非 OPC 自身交付；刑辩、以律师名义出意见书不在交付范围内
  • 独立出具意见、独立经营，是先锋探索者

两轨共享 L0–L2 能力认证；自雇补丁（获客 / 定价 / 合规）叠在 L2 之上、仅自雇轨。门槛卡的是「你能交付哪类业务、责任由谁兜」，不是把人挡在门外——这正是「开放给所有法律人」的落地说明。

造血机制：三层订阅现金造血 头条

主收入 · 三层订阅

  • 标准层：AI 低价/免费订阅（获客入口，合同审查、合规筛查）
  • 判断层：订阅 + 项目制现金（重大合同、股权架构、危机处理）
  • 关系层：月费/年费（嵌入式外部法务部、董事会法律侧陪伴）

辅收入 · 可选股权（彩蛋，极罕见）

  • 仅对「深度绑定、愿赌一张桌」的极少数客户开放
  • 按约定范围与节点、交付完成后发放（非前置）
  • 比例设上限；绝不混淆服务方与投资方两个角色
  • 不是生存依赖，是「我们真站一条船」的罕见礼遇

存在方式三层次（防追问标准口径）

被问「LegalOPC 是不是一家公司 / 谁在管」时，用这段挡回：
① 叙事层——它是一套说法，不归任何机构所有；谁 Adopt 谁就有。
② 分布式个体实体层——真正的载体，是千千万万个独立的个体 OPC：你成立你自己的那一家一人公司，我成立我的，无母公司、无上级。
③ 开放协调层（可选·不私有）——白皮书 / 起草小组 / L0–L2 认证是公共品行业基建，任何人可用可参与，但不拥有 LegalOPC。
反检验：一旦给 LegalOPC 找一个公司实体当「总部」，它就退化成产品/子公司。

边界与合规（写死）

责任不可委托 · 品牌不串台

  • 人担责、AI 为外延：白皮书把责任层设计成可操作机制（风险分级、签字协议、审计记录），不止是道德原则
  • 不称「模型」：对外统一用叙事 / 概念 / 组织形态 / 职业；不称「LegalOPC 是行业级智能体」，说「让法律人成为运营法律行业智能体的超级个体」
  • 品牌不串台：LegalOPC 是独立叙事，不绑定为任何单一产品的标签；对外不挂其他项目 / 产品叙事
  • B 端锚定中小企业（SME）：持续性法务，不把 OPC 创业者当核心付费市场
适合：想以 OPC 方式独立执业、服务中小企业的法律人（受雇轨 / 自雇轨，按业务边界设入场门槛）；需要持续性法务、负担不起传统律师的中小企业。
不适合：把 LegalOPC 当成某家公司产品/加盟体系者；纯诉讼单点需求；拒绝 AI 辅助的团队。
